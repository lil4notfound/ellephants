# 如何读本科

<p class="article-byline"><span>作者：</span>@xucici7-byte</p>

## 主要内容

一定要抓大放小，一定要有优先级意识。高考的逻辑是丢一分都不行，但是大学的逻辑是用最短的时间做最大效率的东西。一定要学会糊弄，绝大多数事情是做了就ok的。要把精力用在刀刃上。所有不重要的事情都主动糊弄。判断事情重要的方式是直接从交付结果往前推一环。（比如要写作业，首要任务是直接开始写这几道题，不是把书从第一页仔细地读到现在的地方）不要总是把精力花在系统的优化上而不花在直接糊弄问题上。

要有计划，同时接受情况的变动。如果情况变动不能被吓傻然后一直呆在原地。要重新制定计划。如果计划涉及到别人（比如作业ddl），很多时候只要提前打招呼都没问题。

生存事项（情绪、身体、杂务）占掉一大部分精力是理所当然的。而且承担这些事是一个独立的为自我负责的成年人的光荣。不能在做计划的时候假设不需要在生存上花精力。按时吃饭睡觉对顺利运行起到80%的作用。

理解和尊重自己的身心状态。我现在学会的自我说明书是：
1. 绝对没有可能开任何上午12点之前的会。如果想通过把见面安排在一大早来让自己早起，那前一天晚上绝对会很焦虑并且熬大夜。
2. 想吃高糖食物说明饿了该吃饭了而且要有正经碳水（面条大米饭这样的主食）
3. 焦虑说明需要吃饭，想死说明需要睡觉
4. 想一直刷小红书说明最近获得的近距离人际关系少了
5. 感官石绝对必要，可以减少捋头发的强迫性肢体重复（强烈推荐握力圈以及【淘宝】https://e.tb.cn/h.8BsJqpe0aEktedS?tk=qTbFTpbnWis CZ005 「adhd专注豆感官硅胶磁力球缓解分心焦虑减压球解压提升专注力玩具」）
6. 桌椅高度和是否有肘托是非常严肃的问题。不舒服的坐姿硬件组合会导致慢性疼痛
7. 每40分钟站起来拉伸、走动和看远处绝对必要。
8. 好的休息是在线下的人际关系里获得了大量关注（并不能总是保证）+干点自己需要稍微努力一下且有成就感的项目（最近是学乐理弹钢琴）
9. 电子笔记（比如ipad+notability）对我而言完全不能用。因为可以撤销还可以无限修改，会花大量精力在把笔记写得干净好看上。
