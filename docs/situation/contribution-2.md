# （原标题）那些年教练让我相信的

<p class="article-byline"><span>作者：</span>火星高级生物</p>

## 内容范围

提到了一些学习方法可能会适合高中生；更多是个人故事和回忆，希望我的教练在指引我的同时，也能带给更多学生启发和鼓舞。

## 主要内容

成长过程中，人总是要后知后觉才会理解一些事。毕业离开一个学校时，光想着怎么跟眼前这些人好好告个别，或是憧憬新生活的开始，恩师们几年的谆谆教诲却只言片语地零落。往往是毕业几年之后，记忆会在某个场景突然鲜活，那些不好理解的道理，在新的环境里重新派上用场，给予我一往无前的勇气。
       大学毕业的今年夏天，思绪掠过四年的喜悦和遗憾，回到长沙市中心的繁华街道，一所全国闻名的高中竟然挤在这逼仄的缝隙里，与一墙之隔的商业街格格不入。四年前离开那里的时候，虽有点不舍却也万分喜悦终于不用再过那般压抑的生活，而离开之后这四年，当我一次又一次情不自禁地想起当时很多很多细节，我惊异地发现，那些年真的改变了我太多太多。这过程中绕不开的一个人，就是我高中的竞赛教练，历届学生都亲切地叫他“陈总”。其实陈总在学校并不担任行政要职，我想在长沙话的语境里，这样的称呼大概是广大学生对一名中学教师最高的礼遇了。
       竞赛组在第一年选拔，高二组班、确定人选，高一正常完成高中课程，晚上、周末和节假日用来上竞赛课、考试、完成额外的竞赛作业。砖块一般的竞赛书和大学教材层层叠叠能垒半个人高，一开始我只是单纯地多花时间看书刷题，但短时间内要学的东西实在太多，考试压力又大，陈总开始给我们讲他的方法论了…… 
       从小到大，学习方法哪个老师不是讲得一套一套的，可学生又听进去多少？把空泛的“方法”讲得让中学生听懂才是陈总的高明之处。马虎大意是几乎所有学生在考试中都会出现的问题，一般老师就说，考试要细心！会做的题做不对就是能力还不够！陈总呢，泡上一壶茶，把我叫到办公室旁边的茶水间，好整以暇地说：你这样，每写一行式子就立刻检查一下，就回头看一眼这一行有没有抄错符号抄错数字，也花不了一秒钟吧，但你要是写完一大段了再检查就很耗时间了是不是？还有你看你这卷面画了这么多杠杠看都看不清，这怎么不看错？你把卷面和草稿纸都给写得像作业一样工整，别乱涂乱画，一行一行式子对齐了写，检查起来也容易嘛。有时我说题目意思理解错了所以没考好，陈总就说：养成好习惯，每道题目读两遍题干再想怎么做，不要上来看到一道题简单，就大喜过望放肆写，结果题目没看清，白忙活一通。那几年他不知道跟我唠叨了多少次我才开窍，把“逐行检查，二次审题”这条金科玉律写在我的作业本封面上，时刻提醒、严格训练。痛苦的适应期有两三个月，熬过去之后，我真的能把所有会做的题都稳稳拿下，这样不需要花太多精力钻研难题也能获得一个不错的分数。第一次，我对“细心”有了如此具象的理解。
       日常学习陈总自有一套要求，不是笼统地让我们每天起早贪黑地坐在教室、把习题册刷完一本又一本，而是希望我们在做题的过程中真正领会。在他的理念中，学习知识的精髓在于总结，大致分为两大类：一类是对具体的知识，比如一道题的解题方法，通常在做题时就顺手写在书或本子的边角，积累得多了，再归纳成篇，有时候还组织同学上台展示自己的题目总结和心得，就像现在的答辩一样把大家都拉到台上遛遛；另一类是对自己的学习状态的评估，每天、每周都要写在他定制格式的本子上，既要有明天或下周的学习计划，也要有对过去一天或一周的反思。思考的内容却没有限制，陈总好像也挺乐意阅读少年们的悲秋伤春，他每周把本子收走检查，但一般不多做评价，毕竟我们生活中的惊涛骇浪——考试考砸了、跟同学闹别扭了、被班主任批评了——在他看来早已波澜不惊吧。而我，从起初抱怨“写这么多总结好麻烦”，渐渐地适应了这个思考和提炼的过程。这些习惯直到今天我还有意识地坚持着，只是，再没有人，会在一个沉闷的上午把我叫到茶水间，一边检查我的笔记和试卷，一边变着花样耐心耐烦好言好语地鼓励我了。
       他大概还教过我一些别的学习方法，我想不太起来了。比起他教我什么“方法”，更重要的是他教会了我寻找方法的“主动意识”。人们常说“授人以鱼不如授人以渔”，陈总给予我们的却比“渔”更先进：他很少给我们亲自授课，也从不强制我们必须看哪本书、做哪些题，更不会强行要求我们认可他的方法和观点，而是让我们自己反思、想办法，遇到问题主动去思考“怎么办”，找到最适合自己的成长节奏，只在必要的时候提供一些建议和启发——我忽然意识到，我竟然在高中时就有幸浅尝了即将到来的研究生生活。而我的自学能力，也是在那几年里被“逼”出来的。制定计划，往前推进，再不断地反馈：如何察觉到学习过程中的问题，如何调整状态和有针对性地解决问题，以及，如何有效地表达问题并求助。今天我也不敢说这几件事情我都做得很好了，只是我想，作为一名准研究生，这是高中教练给我的最珍贵的礼物吧。陈总没有大学教授的头衔，但我很尊敬他，就像尊敬我的导师一样。
       以自学为主的“放养”看似省事，但既要容纳每个学生的个性，又要宏观上把控全组的学习进度，教练工作并不省心。茶水间里，陈总曾无数次与学生们谈心，因此我们对那间屋子都有不少独特的回忆。我记得陈总安慰我“面试没什么可怕的”，告诉我“人生不如意十有八九”，说服我“你的实力一定没问题”……以及，某天站在陈总身后，惊觉他多生出了不少白发，想起来那个晚上他凌晨四点带学生从外地飞回长沙，早晨八点又出现在培训室里。
       那是暑假，但竞赛生和竞赛教练都没有暑假。
       陈总跟我们的父母年龄相仿，除了学习，也跟家里亲切和蔼的长辈一样常常给我们唠一唠他的人生哲学。那时候我还理解不了他说的很多道理，比如他每次说“从某种意义上来讲……”的时候我都疑惑“某种意义”到底是什么意义。毕业后回想起，才开始明白陈总作为资深教练的丰富经验和良苦用心。我能感觉到，陈总在刻意淡化分数的概念和同学之间的竞争意识，鼓励大家积极交流、互相帮助，维护整个竞赛组团结友爱的氛围，也用各种“语言的艺术”不断给我们信心。有时候学习卡壳，陈总敏锐地察觉到我的不安，把我叫到茶水间跟我说：人学习知识的过程是“螺旋式上升”的，很多知识现在不能完全理解，没关系，先放着，不要一直卡在那里，等你学到后面了，甚至将来等你读大学了再看，可能忽然就觉得很简单了。我一时听得费解：什么螺旋？但听君一席话，还真让我少一分焦虑。高二的春天，长沙的天气逐渐闷热，教室里漫上了若有似无的紧张和躁动气息。我又被叫进茶水间，陈总示意我在对面沙发坐下，检查我的笔记和作业，问我最近的学习情况。那段时间可能是成绩不太理想吧，低着头咬着牙不想说话，陈总就无奈地劝说了几句，大意就是一次考不好没关系，“把过程做到极致的人，结果一定不会差。”那一刻，我忽然就坚定地相信了，几年后的今天，这句话还是我的信仰。我试着克制自己不再去过多地想不确定的未来，而是用全部的热情拥抱当下的生活，竭尽全力投入眼前紧要的任务中去。什么是“不太差的结果”？这是一个定义不明又不可证伪的命题，但是，或许，享受过程时，结果已经不那么重要了。
       比赛在高三的九月，赛前半年的冲刺阶段，陈总跟我们唠嗑“考试技巧”的时候就多了起来，他给我们发各种奇奇怪怪的试卷，让我们适应不同的题目风格。陈总倒也没有真的教我们什么了不得的考试技巧，无非是唠叨几句大家都明白的，不能在难题上死磕太长时间、不要一道题做不出就开始慌神等等，其他时候只是要求我们每次考试后自行总结反思，强调“锻炼大赛心态”，时不时请我们去茶水间坐坐。我来长沙之后学了个新词叫“筐瓢”，就是陈总在茶水间里说的：“你看每次大考总有筐瓢的人呐，只要筐瓢的不是你不就行了？”我觉得有点道理。在比赛前那两个月陈总给我们高强度地模拟考试，频率从三天一次逐渐提高到两天一次甚至一天一次，每次考试后，我都很细致地回想今天考试的整个过程：一场三个小时的考试中，我在什么时候、什么情形下有点走神了？遇到难题我卡了多久，值不值得我花这个时间？做完之后还剩下的一点点时间我在做什么，对考试有没有帮助？记录下来，积累多了，归纳成一篇完整的考试预案，把每一个考试时可能遇到的情况都提前想到。后来在极度紧张的关键比赛中，我并没有头顶祥云超水平发挥解出特别难的题目，第二天成绩公布，我惊喜万分：正如陈总所说，只是“没有筐瓢”的我竟然获得了远超预期的成绩——我觉得我的实际实力很难在全省排到这么高的名次，但在最重要的考试中我做到了，为自己拿到了北大最重的一块敲门砖。
       成绩的背后，我也会永远记得，那场比赛前我紧张得几乎一夜没睡。考完，陈总发考试答案让我们估分，我磨蹭到傍晚才跟陈总汇报完情况，然后趴在桌上不知不觉就睡着了……结束了，好累。
       不论陈总平时怎么维护团队氛围，一场重要比赛结束，竞赛组成员还是不得不面临残酷的分流，根据成绩决定去准备高考或其他各项比赛。高一的时候陈总常常拿北大清华刺激我们，督促我们好好学习天天向上，而两年后轮到我们上考场，他只是云淡风轻地说，“多年以后再看，竞赛不过是一场游戏”，“考上清北你也只是高兴四年，四年之后，一切又会不一样”。我想陈总当时说这些只是想让我们在考场上心态放松一点，转眼在北大度过四年，我却不得不承认，陈总说得很对，曾经的竞赛成绩早已云烟，清北只是一层会褪色的光环，而我们终究要学会自己发光。
       话是这么说，作为高中教师，陈总还是想把学生们尽可能送进更好的大学。刚认识陈总的时候，他跟我们说：“一开始我给你们上课，是教练带你们跑；之后你们自主学习、合作学习，是教练陪你们跑；最后，教练就只能看着你们跑了——我没有拿过竞赛金牌，也没有上过清华北大，将来的你们都会比我优秀。”带着他的祝福，三年师生共同努力终于换来了学校升学率的新纪录。毕业那天陈总请全组吃烤肉，饭桌上他问我们：
       “你们知道当竞赛教练最不好的一点是什么吗？” 
       “没有假期？”我们猜。
       “不是。” 
       “工作太忙？” 
       “也不是。”陈总一脸得意，“竞赛教练呀，最不好的就是你们扎堆去清华北大了，除了北京，别的城市我蹭不到饭！不像别的老师，全国到处都有学生！” 
        这可能是我听过的最高级的凡尔赛。
        那天我们频频碰杯聊了很多，烤肉来不及吃我就被饮料灌饱了。欢声笑语中，陈总两次举杯叮嘱我的同学们，“照顾好我们唯一的女生”。很感动，在十五六岁的敏感的年纪，有这样耐心负责的教练指引，还有一群真诚可爱的精神小伙做同学，我可以全然不去理会外界隐约的质疑与偏见，在物理竞赛组快乐自由地生长。特别是读大学之后，时常看到象牙塔的阴暗面在网络新闻里艰难曝光，有的甚至离我很近很近，我不禁庆幸，在我成长的环境中遇到的都是善良的人。陈总可能特别希望给物理领域培养女生吧，高二那年他还给我塞了张贺卡，祝我生日快乐，鼓励我坚持学物理。那张贺卡我现在还带在书包里。也许陈总和同学们有点惯着我，也许我被保护得太好，但确实，他们是我对这世界抱有希望和信任的来源；离家上学的日子里，他们就是家人。
        我们这一届送毕业之后，陈总暂停教练工作扛起了毕业班的高考大旗。我们寒暑假回长沙看他，“蹭不到饭”的他总是执意请我们吃饭。他的朋友圈内容不多，但有往年的学生回来，总要开心地炫耀一番。我和当年的同学们在大学里一直都是好朋友，即使各自忙于学业不再像当年那样朝夕相处，有空也能随时叫出来一起吃艺园东安鸡，嘻嘻哈哈仿佛时光还停留在十七岁时的美好。后来陈总去上海工作，疫情又让我们难以相聚，我们之间的联系渐渐只剩下微信上沉底的聊天框。有天半夜陈总突然在微信群里出现，聊起往事，我发现，那些年陈总让我相信的事情，如今我依然相信着，那些经历沉淀成为了我生命的底色，在我不断去试错、拥抱更大的世界时，它们是我心里生生不息的、燃烧的能量。
        “一棵树摇动另一棵树，一朵云推动另一朵云”，这就是教育的意义吧。
