# 维护指南

本栏目提供投稿和维护所需的操作说明。

## 当前文档

- [写作规范](./writing.md)：页面类型、投稿字段、正文结构和质量要求。
- [参与共建](./contributing.md)：内容表单的填写、审核和自动发布流程。

## 维护入口

- 知识内容通过结构化表单提交，由系统生成页面。
- 站点配置、主题、自动化脚本和目录规则由架构维护者通过 Pull Request 修改。
- 新领域先在[知识地图](../knowledge-map/index.md)中确定边界，再调整目录。
