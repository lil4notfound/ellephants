# 使用指南

想分享一篇自己的文章，或推荐一份值得收藏的资料？这里整理了投稿时会用到的说明。

## 从这里开始

- [写作规范](./writing.md)：了解文章结构、署名、引用和附件要求。
- [参与共建](./contributing.md)：选择“原创内容”或“资源导览”，完成一次投稿。

## 不确定该放在哪里？

先浏览[知识地图](../knowledge-map/index.md)，选择最接近的领域和分支即可。主题词可以用你熟悉的说法填写；如果一篇内容横跨多个领域，也可以补充次要领域。
