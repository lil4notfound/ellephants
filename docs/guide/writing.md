# 写作规范

好的页面应当让读者迅速知道：这里讨论什么、适合谁、需要哪些基础，以及接下来可以去哪里。

## 原创内容

原创投稿可以是文章、教程或课程、笔记、经验与方法，也可以是受数学和物理启发的创作。

- 标题使用清楚、稳定的名称。
- 简介用一至两句话说明范围。
- 主题词选择真正影响内容理解的概念，不必堆叠近义词。
- 教程和课程尽量写明先修知识与阅读收获。
- 经验类内容说明适用的具体处境，不把个人经验包装成普遍结论。
- 使用 Markdown 标题、列表、公式、代码和链接，不插入原始 HTML。

## 资源导览

资源导览不是只贴一个链接。请说明：

1. 资源是谁创作或维护的；
2. 可以从哪里获得；
3. 适合什么读者、解决什么问题；
4. 有哪些门槛、局限或版本差异；
5. 原始资源采用什么许可，或本站为什么可以提供附件。

推荐说明由投稿者署名；第三方资源本身仍遵循原始权利声明。

## 主题词与跨领域内容

每篇内容只保留一个主要位置。主题词用于搜索和整理，不会另外生成一套目录或页面。跨领域内容可以补充次要领域，例如：

- 受量子力学启发的小说，主要放在“毛茸茸”；
- ADHD 学习技巧主要放在“处境”。

如果没有合适的主题词，可以在表单里提出新名称；原词会随投稿保留。

## 引用、附件与隐私

- 事实、引文和资料说明尽量紧邻相关内容。
- 上传附件前确认自己拥有分发权，或文件采用允许再分发的许可。
- 不提交可执行文件、账号凭据、个人敏感信息或无授权转载内容。
- 使用笔名没有问题，但 GitHub Issue 本身是公开的，请不要在正文中填写不希望公开的信息。
