# 知识地图

当前知识库先建设[数学](../mathematics/index.md)和[物理](../physics/index.md)两个一级学科。

## 一级结构

| 一级目录 | 分类方式 | 当前范围 |
| --- | --- | --- |
| [数学](../mathematics/index.md) | 按数学领域划分 | 分析与方程、代数与数论、几何与拓扑、概率统计、应用数学 |
| [物理](../physics/index.md) | 以物理领域为主，方法与实验作为横向板块 | 普通物理与物理思想、力热光电、量子与近代物理、凝聚态、数学物理方法、实验物理 |

## 归类原则

### 通用原则

- 一门课程只有一个主要页面和一个稳定路径。
- 跨领域课程放在最能解释其学习目标的目录，其他目录使用链接引用。
- 同名课程的上下册或不同培养方案原则上共用页面，用别名和章节说明差异。

### 物理目录

- 力学、热学、电磁学、光学等作为主要领域入口。
- 实验物理独立成横向板块，实验页面再标注其关联领域。
- 数学物理方法独立成横向板块，方法页面通过先修与相关课程建立联系。
- `theory`、`experiment`、`methods` 等差异使用标签表达，不再复制目录。
