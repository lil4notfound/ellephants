# ellephants

> 原野象群

ellephants 是一个由社群共同维护的公开知识、经验与创作地图，收录数学、物理、处境和毛茸茸四个领域的原创内容与资源导览。

## 内容范围

- 数学：八个稳定宽分支，细分主题通过知识关系连接。
- 物理：十个稳定宽分支，理论、实验和计算作为横向主题。
- 处境：学习、科研、工作、技术社区、健康与日常经验。
- 毛茸茸：由数学、物理和科学想象启发的创作与推荐。

内容按主要领域归档，并通过标签、先修知识和站内链接建立关联。

## 参与共建

知识内容通过“提交原创内容”或“提交资源导览”Issue 表单投稿，可附带需要由页面提供下载的文件。审核通过后，系统会自动保存附件、生成页面、检查格式并发布。

网站功能、目录结构和视觉交互方面的问题或建议，通过[问题反馈表单](https://github.com/lil4notfound/ellephants/issues/new?template=feedback.yml)提交。反馈会标记为 `feedback` 并等待维护者处理，不会触发内容发布。

站点结构、主题和自动化流程的修改使用分支与 Pull Request。详细要求见 [CONTRIBUTING.md](./CONTRIBUTING.md)。

## 项目结构

```text
ellephants/
├── config/                 # 分类、关系和投稿兼容配置
├── docs/                  # 网站页面与静态资源
│   ├── mathematics/       # 数学内容
│   ├── physics/           # 物理内容
│   ├── situation/         # 处境内容
│   ├── furry/             # 毛茸茸内容
│   ├── guide/             # 写作与投稿说明
│   └── .vitepress/        # VitePress 配置与主题
├── scripts/               # 导航、校验和内容生成工具
└── .github/               # 投稿表单与自动化工作流
```
